# 月度矩阵工作室

把指数、板块、个股的月度收益排成矩阵，格子逐个点亮，导出抖音竖屏 MP4。
不装 Python 库、不装 ffmpeg、不装任何第三方软件。

这是同系列的第四个工具。前三个分别画全市场成交额、个股量价、板块竞速，
它们共用同一套基建（单文件 HTML + 系统自带 csc 编译 exe + `--app` 模式启动 +
MediaRecorder 录制），区别只在核心画面。

---

## 为什么单独成一个应用

矩阵最初是全市场成交额工具里的一种形态，但它和那边格格不入：

- 那个工具按「近1月 / 近3月 / 近6月 / 近1年」取**日线**，受接口「单次最多约 640 根」
  限制，讲不了长周期；
- 矩阵用的是**月K**，一次能取 120 根也就是十年，跟日线完全是两套时间口径。

两套口径挤在一个面板里，「数据区间」选了半天却对矩阵毫无影响，只会让人困惑。
拆出来之后，标的也顺势放开：不再写死上证指数，指数、板块、个股都能画。

## 两种矩阵

### 单标的 年×月

行是年份，列是 1~12 月，最后一列是全年。看**一个标的的季节性**——十年里
哪个月最容易赚钱。统计卡给出最强月、最弱月、上涨月占比、最强单月。

标的三种选法：预设的宽基指数按钮（上证、深证、沪深300、中证500、创业板指、
科创50）、搜索框（代码 / 中文名 / 拼音，指数个股都能搜）、以及任何板块指数代码。

年数可选近 5 年、近 10 年或全部。

### 多标的 标的×月

行是标的，列是最近 N 个月，最后一列是区间累计。一张图看**板块轮动**——
谁在哪个月接棒。统计卡给出冠军、垫底、标的数、跨度。

清单四选一：中证一级行业（10 个，互斥且穷尽）、热门主题（14 个）、宽基指数、
自选股（搜索加入，存在 `localStorage`）。月数可选近 12 / 18 / 24 月。

## 口径与实现要点

数据来自腾讯财经日线接口，`param` 里把 `day` 换成 `month` 就是月K。

- **当月那根必须剔除**：它还没走完，留着的话最近一格显示的是半个月的涨幅。
- **区间收益按月连乘**，不是把月涨跌幅简单相加——相加会高估波动大的区间。
- **多标的模式只保留所有标的都有的月份**，否则某个标的缺一格就会让整行错位。
- **配色深浅按幅度占最大幅度的比例开方**。线性映射下绝大多数月份的幅度都远小于
  极值，会糊成一片暗色，开方之后小涨小跌才看得见。
- 两种矩阵共用同一个网格渲染器：给它行标签、列标签、格子和末列汇总即可，
  差异全在数据组装阶段（`buildYearSpec` / `buildCmpSpec`）。

界面上还有与同系列其它工具一致的部分：视频时长、分辨率、帧率、清晰度、
抖音安全区参考线、隐藏标题、标题文字、图表左右下边距、封面帧导出 PNG、参数记忆。

## 文件说明

| 文件 | 作用 |
|---|---|
| `monthly_matrix_studio.html` | 应用本体，单文件，含界面、抓数、渲染、导出全部逻辑 |
| `MonthlyMatrixStudio.cs` | exe 启动器源码，内嵌上面的 HTML 并以 `--app` 模式拉起浏览器 |
| `build_exe.ps1` | 用系统自带 csc.exe 编译 exe，并打包出 `dist/` 与分发 zip |
| `启动-月度矩阵工作室.cmd` | 免 exe 的降级启动方案，效果完全一致 |
| `app.manifest` | exe 的清单，声明 DPI 感知与兼容性 |
| `gen_icon.py` | 纯 `zlib` + `struct` 手写 PNG 再套 ICO 头，生成 `app.ico`，不依赖 Pillow |

`app.ico`、`dist/`、`*.exe`、`*.zip` 都是生成物，已在 `.gitignore` 中排除。

注意 `build_exe.ps1` 含中文，必须存成 **UTF-8 with BOM**——PowerShell 5.1 会把
无 BOM 的脚本按 ANSI 读，中文全变乱码，解析直接失败。

## 使用方式

直接用：浏览器打开 `monthly_matrix_studio.html`，按 ①②③ 走。

重新打包 exe：改完 HTML 后跑一次

```powershell
.\build_exe.ps1
```

## 已知限制

- **月K 上限约 120 根**，也就是十年出头，再长取不到。
- **多标的最多 14 个**，再多竖屏放不下；少于 2 个没有对比意义。
- **导出耗时等于视频时长**，MediaRecorder 按墙钟给帧打时间戳。
- **产出是分片 MP4**，投稿平台没问题，拖进剪映做二次剪辑偶有时间轴识别异常。
- **需要 Edge 或 Chrome**，H.264 编码能力由浏览器内核提供。
- **exe 未做代码签名**，部分企业级安全软件会直接误删，此时改用 cmd 启动器。
