月度矩阵工作室
================

【怎么用】
双击「月度矩阵工作室.exe」即可，不需要安装任何东西。
按界面上的 ①②③ 走：获取数据 -> 预览播放 -> 导出 MP4。
导出的视频会自动保存到 桌面\月度矩阵视频\ 文件夹。

【两种矩阵】
单标的 年×月：行是年份、列是 1~12 月，末列全年。
              看一个标的十年里哪个月最容易赚钱。
              标的支持指数、板块、个股，搜代码/中文名/拼音都行，
              也可以点预设的宽基指数按钮。
多标的 标的×月：行是标的、列是最近 N 个月，末列区间累计。
              一张图看板块轮动，谁在哪个月接棒。
              清单支持中证一级行业、热门主题、宽基指数、自选股。

【为什么单独做一个应用】
月K 一次能取 120 根也就是十年，跟其它工具按「近1月/近3月」取日线是两套
时间口径，混在一起反而别扭，所以独立出来。

【首次运行的提示】
Windows 可能弹出"已保护你的电脑"蓝色窗口，这是因为本程序没有购买
代码签名证书。点「更多信息」->「仍要运行」即可。

【如果 exe 被杀毒软件删除】
部分企业级安全软件会误删未签名程序。遇到这种情况，改用本文件夹里的
「启动-月度矩阵工作室.cmd」，双击它效果完全一样。
注意 cmd 和 monthly_matrix_studio.html 必须放在同一个文件夹里。

【运行环境要求】
- Windows 10 / 11
- 系统需装有 Microsoft Edge 或 Google Chrome
  （视频的 H.264 编码由浏览器内核提供，所以本程序不需要 ffmpeg）

【数据来源】
腾讯财经行情接口的月K。需要联网。
当月未走完的那一根会自动剔除，否则最近一格显示的是半个月的涨幅。
仅供参考，不构成投资建议。
